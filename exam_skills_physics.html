✅选择题通用策略

一、解题六步法：

  1. 审题：通读题目，圈出关键词和条件（已知量/求量/约束条件）
  2. 联想：快速联想相关物理概念、公式和规律
  3. 选择方法：根据题目特征选择最合适的解法
  4. 执行：快速计算或推理，得出结论
  5. 验证：将结果代入验证或用排除法确认
  6. 标记：不确定的题做标记，留待检查
时间分配：物理选择题建议每题1-2分钟，总时间控制在20分钟内。超时2分钟仍无思路的题先跳过。
🎯选择题核心技巧

1. 排除法（最常用）

  • 逐一验证选项，排除明显错误的选项
  • 适用于：概念判断题、物理现象判断题、单位换算题
  • 关键：注意排除时要找"确定性"错误，不要猜

2. 特殊值法

  • 取满足条件的特殊值代入验证，快速排除或确定答案
  • 适用于：比例题、密度比较题、浮力大小判断题
  • 技巧：取便于计算的数值（如水的密度1.0×10³kg/m³）

3. 代入验证法

  • 将选项逐一代入题目条件验证
  • 适用于：速度计算、密度计算、压强计算
  • 技巧：优先代入中间选项，减少验证次数

4. 图象分析法

  • 根据物理图象（如s-t图、v-t图、I-U图）直观判断
  • 适用于：运动图象题、电阻图象题、晶体熔化图象题
  • 技巧：注意坐标轴含义和图象斜率的物理意义

5. 估算法

  • 不精确计算，通过估算快速排除不合理选项
  • 适用于：生活中的物理量估测题、数量级判断题
  • 技巧：熟记常见物理量的估测值

6. 概念辨析法

  • 用物理概念和规律直接判断选项正误
  • 适用于：物理概念判断题、物理规律应用题
  • 技巧：注意概念的准确性和适用条件

📝 选择题示例

一个人站在平面镜前2m处，若人向平面镜靠近0.5m，则人与镜中像的距离变为（ ）
A. 1m   B. 1.5m   C. 3m   D. 4m
解题思路：平面镜成像特点：像到镜面的距离等于物体到镜面的距离。人向镜面靠近0.5m后，人到镜面距离为2-0.5=1.5m，像到镜面距离也是1.5m，所以人与像的距离为1.5+1.5=3m。选C。
✨ 技巧：平面镜成像"等大、等距、垂直、虚像"四特点，物像到镜面距离始终相等。
✏️填空题核心策略

填空题特点：不需要写出过程，只写答案，但要求完全正确——一步算错，整题零分。

一、三大解题方法：

  • 直接计算法：按题目条件直接用公式计算，最基本的方法
  • 图象分析法：根据图象读取数据或判断规律
  • 推理判断法：根据物理概念和规律进行推理

二、填空题规范要求：

  1. 数值结果注意单位（速度m/s、密度kg/m³、力N等）
  2. 注意有效数字和科学记数法表示
  3. 多空题写所有空，不能遗漏
  4. 物理量用规范符号表示（如v、ρ、F、p等）
  5. 判断题写准确结论，不要写模棱两可的答案

📝 填空题示例

一物体放在水平地面上，受到水平向右的推力F=20N作用匀速直线运动，已知物体所受摩擦力为f，则f=______N，方向______。
解题思路：物体匀速直线运动→受力平衡。水平方向受推力F（向右）和摩擦力f（向左），二力平衡，所以f=F=20N，方向水平向左。
✨ 易错点："匀速直线运动"或"静止"意味着受力平衡，这是受力分析的关键条件。
🔬实验探究题答题规范

一、实验探究题七大要素：

  1. 提出问题：明确要研究什么
  2. 猜想与假设：基于生活经验或已有知识提出猜想
  3. 设计实验：确定实验方法（控制变量法最常用）
  4. 进行实验：按步骤操作，记录数据
  5. 分析数据：比较、归纳，寻找规律
  6. 得出结论：用准确语言描述结论
  7. 评估与交流：分析误差来源，提出改进建议

二、控制变量法（核心方法）：

  • 研究一个量与多个因素的关系时，每次只改变一个因素，保持其他因素不变
  • 适用场景：影响滑动摩擦力的因素、影响压强的因素、影响浮力的因素、影响电阻的因素
  • 答题模板："在保持______不变的条件下，改变______，观察______的变化"
阅卷提示：实验探究题通常按要点给分，结论表述要准确完整。如"在______一定时，______与______成______比"。
📊实验数据分析技巧

1. 表格数据分析：

  • 横向比较：同一组在不同条件下的数据变化
  • 纵向比较：不同组在相同条件下的数据差异
  • 寻找规律：正比、反比、无关等关系

2. 图象分析：

  • 看坐标轴：明确横纵坐标代表的物理量
  • 看图象形状：直线表示正比关系，曲线表示其他关系
  • 看特殊点：起点、拐点、交点的物理含义

3. 误差分析：

误差来源具体表现改进方法
测量工具刻度尺读数误差、天平灵敏度多次测量取平均值
操作不当读数时视线不正、未调零严格按照规范操作
环境因素温度变化、空气阻力控制实验环境条件
实验设计方案本身的系统误差改进实验方案
📝常见实验题类型

类型一：测量型实验

  • 测速度、测密度、测滑轮组机械效率
  • 关键：明确实验原理（公式）、器材选择、步骤设计
  • 注意：读数要估读到分度值的下一位

类型二：探究型实验

  • 探究滑动摩擦力影响因素、探究二力平衡条件、探究凸透镜成像规律
  • 关键：控制变量法的应用、结论表述的准确性
  • 注意：结论要写"在______一定时"的前提条件

类型三：设计型实验

  • 设计测密度的方案、设计测力的方案
  • 关键：原理正确、步骤合理、器材可行
  • 注意：写出实验表达式时注意符号对应

📝 实验探究题示例

在"探究滑动摩擦力大小与哪些因素有关"的实验中：(1)实验原理是什么？(2)为什么要求弹簧测力计沿水平方向匀速拉动？(3)若要探究摩擦力与接触面粗糙程度的关系，应控制什么不变？
解答：
(1)实验原理：二力平衡。弹簧测力计的拉力等于滑动摩擦力。
(2)匀速直线拉动时，物体在水平方向受到的拉力和摩擦力是一对平衡力，大小相等。沿水平方向是为了确保拉力和摩擦力在同一直线上。
(3)应控制压力大小不变，只改变接触面的粗糙程度。
✨ 技巧：实验探究题答题三部曲——①说原理（为什么这样做）②说方法（控制变量法）③说结论（准确表述规律）。
📝计算题答题规范

一、计算题四步法：

  1. 写"解"：每道题开头写"解："，表明开始答题
  2. 列已知：写出已知量和所求（注意带单位和下标）
  3. 写过程：写出公式→代入数据→计算结果（每步带单位）
  4. 作答：最后写"答：..."给出明确结论

二、分步得分原则：

  • 即使不会完整解题，也要写出能写的公式——每个公式都可能得分
  • 代入数据步骤不能省，公式+代入+结果是三步得分点
  • 关键步骤不能跳，尤其是公式的适用条件要说明
阅卷提示：物理计算题通常按步骤给分。公式2-3分，代入数据2-3分，计算结果1-2分，作答1分。即使最终答案错误，公式和代入正确也能获得大部分分数。
📐力学计算题技巧

1. 速度计算题：

  • 公式：v=s/t
  • 注意：单位统一（m/s或km/h），注意路程和时间的对应关系
  • 技巧：画运动过程示意图辅助分析

2. 密度计算题：

  • 公式：ρ=m/V
  • 注意：单位换算（1g/cm³=1×10³kg/m³）
  • 技巧：空心/实心问题用密度比较法或体积比较法

3. 压强计算题：

  • 公式：p=F/S（固体）、p=ρgh（液体）
  • 注意：受力面积S要换算为m²，深度h是从液面到所求点的竖直距离

4. 浮力计算题：

  • 方法：称重法F浮=G-F'、阿基米德原理F浮=ρ液gV排、平衡法F浮=G物（漂浮/悬浮）
  • 注意：判断物体状态（漂浮、悬浮、沉底）是选择公式的前提

5. 功和功率计算题：

  • 公式：W=Fs、P=W/t=Fv、η=W有/W总
  • 注意：力和位移方向要一致，有用功和总功要分清
📄综合计算题技巧

1. 多过程问题：

  • 分阶段分析，每个阶段单独列方程
  • 注意各阶段之间的衔接条件（如速度、位置等）
  • 画运动过程示意图辅助分析

2. 图象综合题：

  • 从图象中提取已知数据
  • 注意图象中特殊点的物理含义
  • 结合公式进行计算

3. 实际应用题：

  • 建立物理模型，将实际问题转化为物理问题
  • 注意单位的统一和换算
  • 检验结果是否符合实际

📝 计算题示例

一个体积为100cm³的实心铁球浸没在水中，求铁球受到的浮力。（ρ水=1.0×10³kg/m³，g=10N/kg）
解：
已知：V球=100cm³=1×10⁻⁴m³，浸没→V排=V球，ρ水=1.0×10³kg/m³，g=10N/kg
由阿基米德原理：
F浮=ρ液gV排=1.0×10³kg/m³×10N/kg×1×10⁻⁴m³=1N
答：铁球受到的浮力为1N。
✨ 技巧：浮力计算题三部曲——①判断物体状态②选择公式③代入计算。注意单位统一。

🕐时间管理实战技巧

1. "三轮做题法"：

  • 第一轮（40-50分钟）：做所有有把握的题，快速准确
  • 第二轮（15-20分钟）：攻克第一轮跳过的中等难度题
  • 第三轮（5-10分钟）：冲击难题+检查

2. "时间红线"机制：

  • 选择题每题红线：2分钟（超时跳过）
  • 填空题每题红线：3分钟（超时跳过）
  • 实验探究题每题红线：7分钟（超时先写能写的步骤）
  • 计算题每题红线：8分钟（超时先写公式）

3. 跳题标记法：

  • 跳过的题在试卷上做明显标记（画圈/折角）
  • 在答题卡对应位置先写"解："，避免漏答
  • 做完后面的题回来时，心态更放松，可能突然有思路
🔍检查策略

一、检查优先级（从高到低）：

  1. 高分题优先：计算题、实验探究题
  2. 易错题优先：计算量大、单位换算多的题
  3. 跳过的题：第一轮没做出的题，回来重新思考
  4. 选择题填空题：快速过一遍，确认填涂位置
  5. 答题卡：检查是否漏涂、错位

二、检查方法：

题型检查方法注意事项
选择题用不同方法重新验证（如排除法→代入法）无充分理由不轻易改答案
填空题重新计算+单位检查+有效数字单位是否正确、是否需要科学记数法
计算题逆运算验证、量纲检查每步单位、公式适用条件
实验题检查结论表述是否完整准确"在______一定时"不能漏写
作图题检查力的方向、虚实线、标注力的大小是否按比例、方向是否正确

三、检查清单：

  • 答题卡填涂位置是否正确
  • 每道题是否都写了答案（无空题）
  • 选择题是否全部填涂（不漏涂）
  • 计算题每步是否带单位
  • 计算题是否写了"解："和"答："
  • 实验题结论是否写了前提条件
  • 作图题是否标注了力和方向
  • 单位换算是否正确（cm²→m²等）
  • 姓名、考号是否填写

🔊声现象学习重点

声现象是八年级上册的重要模块，考查声音的产生与传播、声音的特性、噪声控制等知识。

核心知识点：

  • 声音的产生：物体振动产生声音，振动停止发声停止
  • 声音的传播：需要介质（固/液/气），真空不能传声，声速v=340m/s（15℃空气中）
  • 声音的特性：音调（频率）、响度（振幅）、音色（发声体材料结构）
  • 声的利用：传递信息（回声定位、B超）、传递能量（超声波清洗、碎石）
  • 噪声控制：声源处减弱、传播过程中减弱、人耳处减弱
声现象最大挑战：区分音调、响度、音色三个特性。音调看频率（高低），响度看振幅（大小），音色看材料结构（品质）。
💡声现象考试策略
  1. 概念辨析题：区分"声音的产生"（振动）和"声音的传播"（需要介质）
  2. 特性判断题：音调→频率→高低；响度→振幅→大小；音色→材料→品质
  3. 声速计算：回声测距s=vt/2（注意除以2），注意温度对声速的影响
  4. 噪声题：从三个环节回答减弱噪声的方法
  5. 超声与次声：高于20000Hz为超声，低于20Hz为次声

📝 声现象典型易错

"震耳欲聋"描述的是声音的哪个特性？
正确答案：响度。"震耳欲聋"形容声音很大，响度由振幅决定。
常见错误：误选音调，认为"震"与频率有关。实际上"震耳欲聋"强调声音大（响度大）。
✨ 关键词对应：高/低→音调，大/小/响/轻→响度，好听/难听/辨别→音色。

💡光现象学习重点

光现象是八年级上册的核心模块，考查光的直线传播、反射、折射、色散和凸透镜成像。

核心知识点：

  • 光的直线传播：光在同种均匀介质中沿直线传播，光速c=3×10⁸m/s
  • 光的反射定律：三线共面、两线分居、两角相等
  • 平面镜成像：等大、等距、垂直、虚像（关于镜面对称）
  • 光的折射规律：从空气斜射入水/玻璃，折射角小于入射角
  • 光的色散：白光分解为七色光，三原色红绿蓝
  • 凸透镜成像：u>2f倒立缩小实像、f<u<2f倒立放大实像、u<f正立放大虚像
光现象最大挑战：凸透镜成像规律的记忆和应用。需要熟记"一倍焦距分虚实，二倍焦距分大小"口诀。
💡光现象考试策略
  1. 反射定律作图：法线用虚线，反射角=入射角（都从法线量起）
  2. 平面镜成像作图：利用对称性，像和物关于镜面对称
  3. 折射判断：空气→水/玻璃，折射角<入射角；反之折射角>入射角
  4. 凸透镜成像：口诀"一倍焦距分虚实，二倍焦距分大小；物近像远像变大，物远像近像变小"
  5. 实验题：凸透镜成像实验中，注意蜡烛和光屏的移动方向一致

📝 光现象典型易错

凸透镜焦距为10cm，物体放在距透镜15cm处，光屏上得到的像是什么性质？
解：焦距f=10cm，物距u=15cm，f<u<2f（10<15<20），成倒立、放大的实像。
应用：投影仪/幻灯机原理。
✨ 口诀：u>2f照相机（倒立缩小实像），f<u<2f投影仪（倒立放大实像），u<f放大镜（正立放大虚像）。

🌡️物态变化学习重点

物态变化是八年级上册的重要内容，考查温度、六种物态变化及其吸放热。

核心知识点：

  • 温度：表示物体冷热程度，常用温度计、体温计测量
  • 熔化与凝固：固↔液，熔化吸热、凝固放热
  • 汽化与液化：液↔气，汽化吸热（蒸发+沸腾）、液化放热
  • 升华与凝华：固↔气，升华吸热、凝华放热
  • 晶体与非晶体：晶体有固定熔点（如冰0℃），非晶体无固定熔点（如玻璃）
物态变化最大挑战：六种物态变化的名称、方向和吸放热关系容易混淆。建议画"三角图"记忆。
💡物态变化考试策略
  1. 物态变化判断：先判断初态和末态，再确定物态变化名称
  2. 吸放热判断：熔化、汽化、升华→吸热；凝固、液化、凝华→放热
  3. 晶体熔化图象：水平段表示熔化过程，温度不变，吸热
  4. 沸腾图象：水平段表示沸腾过程，温度不变，吸热
  5. 生活现象：雾、露（液化）；霜、雪（凝华）；冰（凝固）；干冰（升华）

📝 物态变化典型易错

冬天室外冰冻的衣服也会变干，这是什么物态变化？吸热还是放热？
正确答案：升华，吸热。冰直接变成水蒸气，没有经过液态阶段。
常见错误：误认为是熔化（需要温度达到熔点）或汽化（需要先变成液态）。
✨ 判断物态变化：找初态→找末态→确定名称。固态→气态=升华，气态→固态=凝华。

🏃运动与力学习重点

运动与力是八年级下册的核心模块，涵盖机械运动、力、牛顿第一定律、二力平衡等。

核心知识点：

  • 机械运动：参照物、速度v=s/t、匀速直线运动
  • 力：力的三要素（大小、方向、作用点）、力的作用效果
  • 重力：G=mg，方向竖直向下，g=10N/kg
  • 弹力：弹簧测力计原理（在弹性限度内，F与形变成正比）
  • 摩擦力：滑动摩擦力f=μN，影响因素（压力、粗糙程度）
  • 牛顿第一定律：不受力时保持静止或匀速直线运动
  • 二力平衡：等大、反向、共线、同体
运动与力最大挑战：受力分析是核心能力。需要准确画出受力示意图，判断平衡力与相互作用力。
💡运动与力考试策略
  1. 速度计算：注意单位换算，1m/s=3.6km/h
  2. 受力分析：画受力图→判断运动状态→列平衡方程
  3. 二力平衡：必须同时满足四个条件，缺一不可
  4. 惯性题：惯性不是力，不能说"受到惯性作用"
  5. 摩擦力：滑动摩擦力大小只与压力和粗糙程度有关，与速度无关

📝 运动与力典型易错

汽车突然刹车时，乘客会向前倾倒，这是因为什么？
正确答案：乘客具有惯性。刹车时汽车减速，但乘客由于惯性保持原来的运动状态，所以向前倾倒。
常见错误：说"受到向前的力"或"受到惯性作用"。惯性是物体的属性，不是力。
✨ 惯性表述：一切物体都有惯性，惯性大小只与质量有关，与速度无关。

⚖️质量与密度学习重点

质量与密度是八年级上册的重点计算模块，考查天平使用、密度公式及计算。

核心知识点：

  • 质量：物体所含物质的多少，单位kg，用天平测量
  • 密度：ρ=m/V，某种物质单位体积的质量，单位kg/m³或g/cm³
  • 天平使用：放平→归零→调平衡→左物右码→读数
  • 量筒使用：读数时视线与液面齐平
  • 密度计算：ρ=m/V，m=ρV，V=m/ρ
  • 空心实心：比较密度法、比较体积法、比较质量法
质量与密度最大挑战：密度计算中的单位换算和空心实心问题的判断方法。
💡质量与密度考试策略
  1. 天平读数：右盘砝码质量+游码示数=物体质量
  2. 密度计算：注意单位统一，1g/cm³=1×10³kg/m³
  3. 空心问题：假设实心算出体积，与实际体积比较；或算出实际密度与物质密度比较
  4. 混合密度：ρ混=m总/V总，不能用密度平均值
  5. 实验题：测固体密度（天平+量筒）、测液体密度（剩余法减小误差）

📝 质量与密度典型易错

一个铝球质量为54g，体积为30cm³，判断是空心还是实心？（ρ铝=2.7g/cm³）
解法（比较体积法）：
假设实心，V实=m/ρ=54g÷2.7g/cm³=20cm³
因为V实=20cm³<V实际=30cm³，所以铝球是空心的。
空心部分体积=30-20=10cm³
✨ 技巧：空心实心判断三种方法——比密度、比体积、比质量，选最简便的计算。

⚡电学基础学习重点

电学基础是物理考试中分值高、综合性强的模块，涵盖电流、电压、电阻和欧姆定律。

核心知识点：

  • 电流：I=Q/t，单位A，串联电流处处相等，并联干路等于各支路之和
  • 电压：U，单位V，串联总电压等于各部分之和，并联电压相等
  • 电阻：R，单位Ω，决定因素（材料、长度、横截面积、温度）
  • 欧姆定律：I=U/R，导体中的电流与电压成正比，与电阻成反比
  • 串并联电路：串联R总=R₁+R₂，并联1/R总=1/R₁+1/R₂
  • 电功电功率：W=UIt，P=UI=I²R=U²/R
电学最大挑战：电路分析（串并联判断）和欧姆定律的综合应用。需要掌握画等效电路图的能力。
💡电学考试策略
  1. 电路分析：先判断串并联，再画等效电路图
  2. 欧姆定律：注意I、U、R必须是同一导体、同一时刻的量
  3. 电表判断：电流表串联、电压表并联，注意量程选择
  4. 比值问题：串联正比分压（U₁/U₂=R₁/R₂），并联反比分流（I₁/I₂=R₂/R₁）
  5. 安全用电：不接触低压带电体，不靠近高压带电体

📝 电学典型易错

两个电阻R₁=10Ω、R₂=20Ω串联接在6V电源上，求通过R₁的电流和R₂两端的电压。
解：
串联总电阻R=R₁+R₂=10+20=30Ω
电路电流I=U/R=6V/30Ω=0.2A
串联电流处处相等，I₁=I=0.2A
U₂=IR₂=0.2A×20Ω=4V
✨ 技巧：串联电路"电流处处相等"是解题突破口，先求总电阻再求总电流。

🔥内能与热机学习重点（初三）

内能是九年级的热学核心模块，考查分子动理论、内能、比热容、热机、能量转化。

核心知识点：

  • 分子动理论：物质由分子组成，分子在不停地做无规则运动，分子间有引力和斥力
  • 内能：物体内所有分子动能和分子势能的总和，一切物体都有内能
  • 改变内能方式：做功（机械能→内能）和热传递（高温→低温）
  • 比热容：c=Q/(mΔt)，水的比热容最大c水=4.2×10³J/(kg·℃)
  • 热值：1kg燃料完全燃烧放出的热量，q=Q/m
  • 热机：四冲程（吸气、压缩、做功、排气），做功冲程内能→机械能
内能模块最大挑战：区分"做功改变内能"和"热传递改变内能"，以及比热容计算中Δt（末温减初温）的正确使用。
💡内能考试策略
  1. 分子动理论题：扩散现象说明分子在无规则运动，"温度越高扩散越快"
  2. 内能判断：同一物体温度升高内能增大，但内能增大温度不一定升高（如晶体熔化）
  3. 做功与热传递：摩擦生热、压缩气体→做功；晒太阳、烧水→热传递
  4. 比热容计算：Q=cmΔt，注意Δt=末温-初温，质量单位用kg
  5. 热机效率：η=W有用/Q放×100%，热机做功冲程是唯一对外做功的冲程

📝 内能典型易错

"热传递和做功都能改变内能"，如何判断？搓手取暖和用热水袋取暖分别属于哪种方式？
正确答案：搓手取暖属于做功（克服摩擦做功，机械能→内能）；用热水袋取暖属于热传递（高温热水→低温手）。
常见错误：将"摩擦生热"误认为热传递。判断关键：是否有"做功的位移"或"高温物体与低温物体直接接触"。
✨ 判断口诀：摩擦压缩必做功，接触传热是热传递；做功内能来改变，热传递看温度差。

🔌电流与电路学习重点（初三）

电流与电路是九年级电学的入门基础，考查电荷、电流、电路组成、串并联、电流电压测量。

核心知识点：

  • 电荷：正负电荷、摩擦起电（电子转移）、电荷间相互作用（同斥异吸）
  • 电流：电荷定向移动形成电流，方向：正电荷定向移动方向，单位A
  • 电路组成：电源、用电器、开关、导线四要素；通路、断路、短路三种状态
  • 串并联：串联电流处处相等；并联各支路互不影响
  • 电流表：串联接入，正进负出，不能直接接电源两极
  • 电压表：并联接入，量程选择，可直接测电源电压
电路模块最大挑战：电路图的识别与设计、电流表电压表的正确连接、短路的判断。
💡电流与电路考试策略
  1. 电路判断：电流表当导线、电压表当断路，去掉电表再判断串并联
  2. 故障分析：电流表无示数电压表有示数→断路；电流过大→短路
  3. 电路设计题：按要求逐条设计，开关控制并联电路各支路时接在支路上
  4. 读数技巧：先看量程再读数，电流表0-0.6A与0-3A、电压表0-3V与0-15V相差5倍
  5. 实物图连接：从电源正极出发，按电流路径逐个连接，注意电表正负接线柱

📝 电路典型易错

正确答案：串联电流处处相等，I₁=I₂。灯丝断了电路断路，另一个灯泡也不亮。
常见错误：认为离电源近的灯泡电流大。串联电路中电流处处相等，只是电阻大的分压大。
✨ 记忆：串联"流等压分"，并联"压等流分"；串联断路全不亮，并联互不影响。

📏欧姆定律学习重点（初三）

欧姆定律是九年级电学的中枢，考查欧姆定律、串并联计算、伏安法测电阻、动态电路。

核心知识点：

  • 欧姆定律：I=U/R，导体中电流与电压成正比，与电阻成反比（同体同时）
  • 电阻：导体对电流的阻碍作用，与材料、长度、横截面积、温度有关
  • 串联电路：R=R₁+R₂，电流处处相等，电压正比分压U₁/U₂=R₁/R₂
  • 并联电路：1/R=1/R₁+1/R₂，各支路电压相等，电流反比分流I₁/I₂=R₂/R₁
  • 伏安法测电阻：原理R=U/I，滑动变阻器保护电路+多次测量求平均
  • 动态电路：滑片移动、开关通断引起电路变化分析
欧姆定律最大挑战：I、U、R的"同体同时"对应关系，以及动态电路中电表示数的变化分析。
💡欧姆定律考试策略
  1. 计算对应：三个量必须对应同一导体同一时刻，加下标区分如I₁=U₁/R₁
  2. 动态电路口诀："串大流小压大"，变阻器阻值增大→总电阻增大→总电流减小
  3. 伏安法实验：滑动变阻器初始调最大阻值，多次测量取平均减小误差
  4. I-U图象：同一电阻I-U图象是过原点的直线，斜率倒数表示电阻
  5. 求电阻方法：串联分压求电压、并联分流求电流，再结合欧姆定律

📝 欧姆定律典型易错

常见错误：直接用9V除以灯泡电阻，忽视串联分压。
✨ 技巧：串联分压U总=U₁+U₂，先求已知电阻电压，再用欧姆定律求所需电阻。

⚡电功率学习重点（初三）

电功率是九年级电学的最重要模块（中考压轴常客），考查电功、电功率、焦耳定律、额定功率、测量小灯泡功率。

核心知识点：

  • 电功：W=UIt，单位J或kW·h（1kW·h=3.6×10⁶J）
  • 电功率：P=W/t=UI=I²R=U²/R，单位W
  • 额定功率与实际功率：额定电压下功率为额定功率，实际功率随实际电压变化
  • 焦耳定律：Q=I²Rt，电热器（纯电阻）Q=W=Pt
  • 测小灯泡电功率：原理P=UI，需测额定电压下的电流
  • 电表读数：电能表读数（最后一位小数）、测量电功率
电功率最大挑战：额定功率与实际功率的区别（灯越亮实际功率越大），以及电功率三公式的灵活选择。
💡电功率考试策略
  1. 公式选择：串联比电流用P=I²R，并联比电压用P=U²/R，已知UI直接用P=UI
  2. 灯泡亮度：实际功率越大灯越亮，两灯串联时电阻大的亮（电流相等），并联时电阻小的亮（电压相等）
  3. 档位问题：电热器"高温档=功率大"，根据P=U²/R，电阻小功率大（多挡位电路）
  4. 测功率实验：移动滑片使电压表示数等于额定电压，再读电流算额定功率
  5. 电能表测功率：P=n/N×3.6×10⁶/t（n转数，N为每度转数）

📝 电功率典型易错

标有"220V 100W"的灯泡，接在110V的电压下，实际功率约为多少？
解：电阻R=U²/P=220²/100=484Ω；实际功率P实=U实²/R=110²/484=25W。
常见错误：误认为实际功率是额定功率的一半。实际功率与电压的平方成正比，110V是220V的一半，功率变为1/4。
✨ 记忆：P实/P额=(U实/U额)²，电压减半功率变四分之一。

🏠生活用电与电与磁学习重点（初三）

🏃力学高频易错点
1. 惯性与力的混淆▼

错误表现：说"受到惯性作用"或"惯性力"

正确理解：惯性是物体的固有属性，一切物体都有惯性，惯性不是力。只能说"具有惯性"或"由于惯性"。

口诀："惯性是属性，不是力；只能说具有，不能说受到。"

2. 平衡力与相互作用力混淆▼

错误表现：把平衡力当作相互作用力，或反之

平衡力：作用在同一物体上的两个力（如书受重力和桌面支持力）

相互作用力：作用在两个不同物体上的力（如书压桌面和桌面支持书）

关键区分：看是否作用在同一个物体上。

3. 速度单位换算错误▼

错误表现：1m/s=3.6km/h记错或方向搞反

正确换算：1m/s=3.6km/h，1km/h=1/3.6m/s≈0.28m/s

推导：1m/s=1×3.6km/h=3.6km/h

4. 重力方向表述错误▼

错误表现：说重力方向是"垂直向下"或"指向地心"

正确说法：重力方向是"竖直向下"。垂直向下需要说明垂直于哪个面，竖直向下是固定方向。

5. 滑动摩擦力大小判断错误▼

错误表现：认为速度越大摩擦力越大，或接触面积越大摩擦力越大

正确理解：滑动摩擦力大小只与压力大小和接触面粗糙程度有关，与速度、接触面积无关。

6. 压强公式混用▼

错误表现：液体压强用p=F/S计算

正确做法：固体压强用p=F/S，液体压强用p=ρgh。但规则形状的液体也可以用p=F/S。

注意：p=F/S中S是受力面积，单位必须换算为m²。

7. 浮力方向表述错误▼

错误表现：说浮力方向"向上"或"垂直向上"

正确说法：浮力方向是"竖直向上"。

注意：无论物体在液体中的位置如何，浮力方向始终竖直向上。

⚡电学高频易错点
1. 串并联电路判断错误▼

错误表现：有电压表的电路不会判断串并联

正确做法：分析电路时，电流表当作导线（短路），电压表当作断路（开路），先判断用电器的连接方式。

2. 欧姆定律I、U、R不对应▼

错误表现：用R₁的电压除以R₂的电阻

正确做法：I=U/R中三个量必须对应同一导体、同一时刻。要加下标区分，如I₁=U₁/R₁。

3. 电表量程读数错误▼

错误表现：量程选错导致读数错误

电流表：0-0.6A（分度值0.02A）和0-3A（分度值0.1A），读数相差5倍

电压表：0-3V（分度值0.1V）和0-15V（分度值0.5V），读数相差5倍

4. 滑动变阻器接线错误▼

错误表现：接"两上"或"两下"接线柱

正确接法："一上一下"，即上面两个接线柱选一个，下面两个选一个。接"两上"相当于导线（阻值为0），接"两下"相当于定值电阻（阻值最大且不变）。

5. 短路与断路混淆▼

断路：电路某处断开，电路中无电流。电流表无示数，电压表可能测电源电压。

短路：导线直接连接用电器两端。被短路的用电器不工作，电流很大。

判断技巧：电压表有较大示数但电流表无示数→断路；电流过大→短路。

6. 电路故障分析不全面▼

错误表现：只考虑一种故障可能

正确做法：电路故障可能是断路或短路，需要根据电表示数综合判断。列出所有可能，逐一排除。

🔊声光高频易错点
1. 音调、响度、音色混淆▼

错误表现：将"震耳欲聋"判断为音调高

正确理解：音调→频率→高低（高音/低音）；响度→振幅→大小（大声/小声）；音色→材料→品质（分辨不同声音）。

关键词对应：高/低/尖锐→音调；大/小/响/轻→响度；好听/辨别→音色。

2. 真空能否传声/传光▼

错误表现：认为真空可以传声或真空不能传光

正确理解：声音传播需要介质，真空不能传声；光可以在真空中传播（光不需要介质）。

3. 入射角/反射角从哪里量起▼

错误表现：从反射面量起

正确做法：入射角和反射角都是从法线量起的。法线是垂直于反射面的虚线。

4. 平面镜成像距离计算▼

错误表现：像到物体的距离等于物到镜面的距离

正确理解：像到镜面距离=物到镜面距离。像到物体距离=2×物到镜面距离。

5. 凸透镜成像规律记混▼

口诀记忆："一倍焦距分虚实，二倍焦距分大小"

u>2f：倒立缩小实像（照相机）

f<u<2f：倒立放大实像（投影仪）

u<f：正立放大虚像（放大镜）

u=2f：倒立等大实像（分界点）

u=f：不成像（分界点）

6. 实像与虚像混淆▼

实像：实际光线会聚形成，能呈现在光屏上，倒立。如小孔成像、凸透镜成实像。

虚像：光线的反向延长线形成，不能呈现在光屏上。如平面镜成像、凸透镜成虚像。

🌡️热学高频易错点
1. 物态变化名称记错▼

六种物态变化：

固态→液态：熔化（吸热）

液态→固态：凝固（放热）

液态→气态：汽化（吸热）

气态→液态：液化（放热）

固态→气态：升华（吸热）

气态→固态：凝华（放热）

口诀："熔汽升吸热，凝液凝放热"（注意"凝"出现两次：凝固和凝华都放热）

2. 晶体熔化时温度是否变化▼

错误表现：认为晶体熔化时温度升高

正确理解：晶体熔化时温度保持不变（在熔点），但需要继续吸热。非晶体熔化时温度持续升高，没有固定熔点。

3. 蒸发与沸腾的区别▼

蒸发：在任何温度下发生，只在液体表面进行，缓慢

沸腾：在沸点时发生，液体表面和内部同时进行，剧烈

共同点：都是汽化现象，都吸热

4. "白气"是什么物态变化▼

错误表现：认为"白气"是水蒸气

正确理解："白气"不是水蒸气（水蒸气是无色透明的），而是水蒸气遇冷液化形成的小水珠。所以"白气"的形成是液化现象。

5. 体温计的特殊性▼

错误表现：认为体温计和普通温度计一样不能离开人体读数

正确理解：体温计有缩口结构，离开人体后水银不会自动回落，因此可以离开人体读数。使用前需要甩一甩使水银回落。

6. 沸点与气压的关系▼

正确理解：液体的沸点随气压增大而升高，随气压减小而降低。

应用：高压锅利用增大气压来提高沸点，使食物更快煮熟。高海拔地区气压低，水的沸点低于100℃。

🔬实验操作高频易错点
1. 天平使用"左物右码"记反▼

错误表现：左盘放砝码，右盘放物体

正确做法：左盘放物体，右盘放砝码。因为游码向右移动相当于在右盘加小砝码。

读数：物体质量=砝码总质量+游码示数。

2. 量筒读数视线问题▼

错误表现：仰视或俯视读数

正确做法：视线与液面最低处保持水平。仰视读数偏小，俯视读数偏大。

3. 测密度实验顺序错误▼

测固体密度：先测质量（天平），再测体积（量筒）。如果先测体积再测质量，固体沾水会导致质量偏大，密度偏大。

测液体密度：先测总质量（烧杯+液体），倒入量筒测体积，再测剩余质量（烧杯+剩余液体）。这样可以避免烧杯壁残留液体带来的误差。

4. 控制变量法表述不完整▼

错误表现：结论不写前提条件

正确表述："在______一定时，______与______成正比/反比。"必须写出"在______一定时"的前提条件。

5. 凸透镜成像实验操作错误▼

错误表现：蜡烛、凸透镜、光屏不在同一高度

正确做法：蜡烛、凸透镜、光屏依次放在光具座上，调整三者中心在同一高度，目的是使像成在光屏中央。

6. 弹簧测力计使用前未调零▼

错误表现：直接使用未调零的弹簧测力计

正确做法：使用前先检查指针是否在零刻度线处，不在则需要调零。测量时力的方向要与弹簧轴线方向一致。

⚡初三电学高频易错点
1. 电功率公式选择错误▼

错误表现：不管条件一律用P=UI

正确做法：串联电路比电流方便用P=I²R（电流相等）；并联电路比电压方便用P=U²/R（电压相等）；已知UI直接用P=UI。

2. 额定功率与实际功率混淆▼

错误表现：认为灯泡接在任何电压下功率都是额定功率

正确理解：额定功率是额定电压下的功率，实际功率随实际电压变化。P实/P额=(U实/U额)²，实际电压减半，实际功率变为原来的1/4。

3. 焦耳定律适用范围错误▼

错误表现：非纯电阻电路（如电动机）也直接用Q=UIt=Pt算热量

正确理解：焦耳定律Q=I²Rt对所有电路适用；但Q=W=Pt只适用于纯电阻电路。电动机电路消耗的电能W>产生的热量Q。

4. 动态电路分析错误▼

错误表现：不看电路结构变化，凭感觉判断电表示数

正确做法：先判断开关通断/滑片位置改变了电路结构，再按"总电阻→总电流→分电压/分电流"顺序分析。口诀"串大流小压大"。

5. 电表量程与读数错误▼

错误表现：读表时忘了乘分度值或量程看错

正确做法：电流表0-0.6A分度值0.02A、0-3A分度值0.1A；电压表0-3V分度值0.1V、0-15V分度值0.5V。读数前先确认接线柱所选量程。

6. 电能表读数错误▼

错误表现：把电能表最后一位整数位当整数读

正确理解：电能表最后一位数字是小数位，读数单位是kW·h。电能表测功率：P=n/N×3.6×10⁶/t（n为转数，N为每kW·h转数，t为秒）。

🔥初三热学（内能）高频易错点
7. 比热容计算Δt用错▼

错误表现：Δt用初温减末温，或把"升高到"当"升高了"

正确理解：Δt=末温-初温。"升高了10℃"指Δt=10℃；"升高到10℃"指末温t=10℃（还要减初温）。质量单位用kg，比热容单位J/(kg·℃)。

8. 热值单位与计算错误▼

错误表现：固体燃料热值q的单位J/m³，气体用J/kg，混用

正确理解：固体液体燃料热值单位J/kg，气体燃料热值单位J/m³。Q=mq（固体液体）或Q=Vq（气体）。热值是燃料的特性，与质量无关。

9. 做功与热传递改变内能判断错误▼

错误表现：把摩擦生热当成热传递

正确理解：摩擦生热、压缩气体做功→做功改变内能；高温物体与低温物体接触传热→热传递改变内能。做功是能量的转化，热传递是能量的转移。

10. 热机冲程判断错误▼

错误表现：认为四个冲程都对外做功

正确理解：只有做功冲程对外做功（内能→机械能）；压缩冲程是机械能→内能。四冲程一个循环：吸气、压缩、做功、排气，曲轴转两圈，做功一次。

🔊例1：回声测距
一个人对着山崖喊话，经过2s后听到回声，求人到山崖的距离。（空气中声速v=340m/s）

解：

声音传播的总路程 s总 = v×t = 340m/s × 2s = 680m

人到山崖的距离 s = s总/2 = 680/2 = 340m

答：人到山崖的距离为340m。

解题技巧：回声测距问题，声音走过的路程是往返的，所以人到障碍物距离=声速×时间÷2。
🔊例2：声音三特性辨析
以下说法中，分别描述声音的哪个特性？(1)"引吭高歌"(2)"声音刺耳"(3)"闻其声知其人"

解：

(1)"引吭高歌"中的"高"指声音大→响度（振幅决定）

(2)"声音刺耳"形容声音尖锐→音调高（频率决定）

(3)"闻其声知其人"指能辨别不同人的声音→音色（发声体材料结构决定）

解题技巧：高/低→音调，大/小/响/轻→响度，辨别/好听→音色。
🔊例3：减弱噪声的途径
下列措施中，分别在什么环节减弱噪声？(1)摩托车安装消声器(2)高速公路两侧安装隔音墙(3)戴上耳塞

解：

(1)摩托车安装消声器→在声源处减弱噪声

(2)高速公路两侧安装隔音墙→在传播过程中减弱噪声

(3)戴上耳塞→在人耳处减弱噪声

解题技巧：减弱噪声三途径——声源处、传播过程中、人耳处。看措施在哪里实施就属于哪个环节。
💡例4：平面镜成像计算
身高1.6m的同学站在竖直放置的平面镜前2m处，问：(1)他在镜中的像高多少？(2)像到他本人的距离是多少？(3)若他向镜面走近0.5m，像到镜面的距离变为多少？

解：

(1)平面镜成像"等大"，像高=物高=1.6m

(2)像到镜面距离=物到镜面距离=2m，像到本人距离=2+2=4m

(3)向镜面走近0.5m后，物到镜面=2-0.5=1.5m，像到镜面=1.5m

解题技巧：平面镜成像四特点——等大、等距、垂直、虚像。像与物关于镜面对称。
💡例5：凸透镜成像应用
凸透镜焦距f=10cm。(1)物体放在25cm处，光屏上成什么像？(2)物体从25cm处向透镜靠近到15cm处，像如何变化？(3)物体放在5cm处，成什么像？

解：

(1)u=25cm>2f=20cm→倒立、缩小、实像（照相机原理）

(2)从u=25cm到u=15cm（f<u<2f）→像从缩小实像变为放大实像，且像变大、像距变大

(3)u=5cm<f=10cm→正立、放大、虚像（放大镜原理）

口诀：一倍焦距分虚实，二倍焦距分大小；物近像远像变大，物远像近像变小。
💡例6：光的折射判断
一束光从空气斜射入水中，入射角为40°，则折射角可能为多少？

解：

光从空气斜射入水中，折射角小于入射角。

入射角=40°，所以折射角<40°，可能为30°（具体值取决于水的折射率）。

注意：折射角和入射角都是从法线量起的。

解题技巧：空气→水/玻璃，折射角<入射角；水/玻璃→空气，折射角>入射角。"空气角大"。
🏃例7：速度计算
一辆汽车在平直公路上匀速行驶，前半程速度为60km/h，后半程速度为40km/h，求全程的平均速度。

解：

设全程为2s，前半程和后半程各为s

前半程用时 t₁=s/60 (h)

后半程用时 t₂=s/40 (h)

总时间 t=t₁+t₂=s/60+s/40=s(2+3)/120=5s/120=s/24

平均速度 v=2s/t=2s/(s/24)=48 km/h

答：全程平均速度为48km/h。

解题技巧：平均速度=总路程÷总时间，不是速度的平均值！分段计算时注意路程和时间的对应关系。
⚖️例8：密度计算
一个质量为178g的铜球，体积为30cm³。（ρ铜=8.9g/cm³）(1)判断是否空心；(2)若空心，空心部分体积多大？(3)若空心部分注满水，总质量多少？

解：

(1)假设实心：V实=m/ρ=178÷8.9=20cm³

因为V实=20cm³<V球=30cm³，所以铜球是空心的

(2)空心体积V空=V球-V实=30-20=10cm³

(3)注满水：m水=ρ水×V空=1.0×10=10g

总质量m总=178+10=188g

解题技巧：空心实心判断——假设实心算体积，与实际体积比较。空心部分注水/注其他物质，用ρ=m/V计算。
🏊例9：浮力计算
一个物体重力为6N，体积为5×10⁻⁴m³，将其浸入水中（ρ水=1.0×10³kg/m³，g=10N/kg）。(1)求物体完全浸没时受到的浮力；(2)物体静止后是漂浮、悬浮还是沉底？

解：

(1)完全浸没时：F浮=ρ水gV排=1.0×10³×10×5×10⁻⁴=5N

(2)比较浮力与重力：F浮=5N<G物=6N

浮力小于重力→物体沉底

验证：物体密度ρ物=m/V=G/(gV)=6/(10×5×10⁻⁴)=1.2×10³kg/m³>ρ水

ρ物>ρ液→沉底，与结论一致。

解题技巧：判断浮沉——比较ρ物与ρ液（或比较F浮与G物）。ρ物<ρ液漂浮，ρ物=ρ液悬浮，ρ物>ρ液沉底。
⚡例10：欧姆定律计算
如图，R₁=10Ω、R₂=20Ω串联接在12V电源上。求：(1)电路总电阻；(2)电路中的电流；(3)R₁和R₂两端的电压。

解：

(1)串联总电阻R=R₁+R₂=10+20=30Ω

(2)I=U/R=12V/30Ω=0.4A

(3)串联电流处处相等：I₁=I₂=I=0.4A

U₁=I₁R₁=0.4×10=4V

U₂=I₂R₂=0.4×20=8V

验证：U₁+U₂=4+8=12V=U ✓

解题技巧：串联电路先求总电阻→再求总电流→最后求各部分电压。串联正比分压：U₁/U₂=R₁/R₂。
⚡例11：并联电路计算
R₁=10Ω、R₂=20Ω并联接在6V电源上。求：(1)通过R₁和R₂的电流；(2)干路总电流；(3)电路总电阻。

解：

(1)并联电压相等：U₁=U₂=U=6V

I₁=U₁/R₁=6/10=0.6A

I₂=U₂/R₂=6/20=0.3A

(2)干路电流I=I₁+I₂=0.6+0.3=0.9A

(3)R=U/I=6/0.9≈6.67Ω

或用公式：1/R=1/R₁+1/R₂=1/10+1/20=3/20

R=20/3≈6.67Ω

解题技巧：并联电路先求各支路电流→再求干路总电流。并联反比分流：I₁/I₂=R₂/R₁。
⚡例12：滑动变阻器问题
如图，R₁=20Ω为定值电阻，R为滑动变阻器，电源电压6V不变。当滑片P在中点时，电流表示数为0.2A。(1)求滑动变阻器最大阻值；(2)当滑片在最右端时，电流表示数多大？

解：

(1)滑片在中点，R接入阻值=R_max/2

R总=U/I=6/0.2=30Ω

R_max/2=R总-R₁=30-20=10Ω

R_max=20Ω

(2)滑片在最右端，R=R_max=20Ω

R总'=R₁+R=20+20=40Ω

I'=U/R总'=6/40=0.15A

解题技巧：滑动变阻器问题关键——明确滑片位置与接入阻值的关系，注意"一上一下"接法。
🏆例13：力学综合
一个边长为10cm的正方体木块漂浮在水面，露出水面的高度为4cm。（ρ水=1.0×10³kg/m³，g=10N/kg）求：(1)木块底面受到的水的压强；(2)木块受到的浮力；(3)木块的密度。

解：

(1)木块浸入水中的深度h=10-4=6cm=0.06m

p=ρ水gh=1.0×10³×10×0.06=600Pa

(2)木块底面积S=0.1×0.1=0.01m²

浮力F浮=pS=600×0.01=6N

（或用F浮=ρ水gV排=1.0×10³×10×0.01×0.06=6N）

(3)漂浮时F浮=G木

m木=G/g=6/10=0.6kg

V木=0.1³=0.001m³

ρ木=m/V=0.6/0.001=0.6×10³kg/m³

综合技巧：漂浮问题核心是F浮=G物，结合p=ρgh、F浮=ρ液gV排综合求解。
🏆例14：压强综合
将一个质量为500g、底面积为50cm²的物体放在水平桌面上。求：(1)物体对桌面的压力；(2)物体对桌面的压强。（g=10N/kg）

解：

(1)水平面上：F=G=mg=0.5kg×10N/kg=5N

(2)S=50cm²=0.005m²

p=F/S=5/0.005=1000Pa

答：压力为5N，压强为1000Pa。

综合技巧：固体压强计算——水平面上压力F=G=mg，注意面积单位cm²要换算为m²。
⚡例15：电功率综合计算（中考压轴）
标有"6V 3W"的小灯泡与滑动变阻器串联接在9V电源上，灯丝电阻不变。(1)求灯丝电阻；(2)要使灯泡正常发光，变阻器接入电阻为多少？(3)若变阻器接入电阻为12Ω，灯泡实际功率为多少？

解：

(1)由P=U²/R得：R=U²/P=6²/3=12Ω

(2)灯泡正常发光需U₁=6V，I=P/U=3/6=0.5A；串联分压U₂=9-6=3V；R₂=U₂/I=3/0.5=6Ω

(3)串联总电阻R总=12+12=24Ω；I=U/R总=9/24=0.375A；P实=I²R=0.375²×12≈1.69W

中考电功率压轴解题三步：先求电阻（R=U²/P）→判断灯泡状态→用实际电流电压求实际功率。
⚡例16：多挡位电热器问题
某电热器有两个发热电阻R₁=44Ω、R₂=88Ω，可串联或单独使用。电源电压220V。求：(1)单独用R₁时的功率；(2)串联时的功率；(3)哪个是高温挡？

解：

(1)单独R₁：P₁=U²/R₁=220²/44=1100W

(2)串联R串=44+88=132Ω；P串=U²/R串=220²/132≈366.7W

(3)由P=U²/R，电压相同时电阻越小功率越大，单独R₁（1100W）是高温挡

多挡位电路核心：P=U²/R，电压不变时电阻小→功率大→高温挡。串联电阻大功率小（低温），并联电阻小功率大（高温）。
⚡例17：动态电路电表示数变化
如图，R₁为定值电阻，R₂为滑动变阻器，串联接在电源上。滑片P向右移动时：(1)电路中电流如何变化？(2)电压表V₁（测R₁）示数如何变化？(3)电压表V₂（测R₂）示数如何变化？

解：

(1)滑片右移→R₂接入电阻变大→总电阻变大→电源电压不变→电流变小

(2)R₁阻值不变，电流变小→U₁=I×R₁变小，V₁示数变小

(3)U₂=U-U₁，电源电压不变，U₁变小→U₂变大，V₂示数变大

动态电路分析口诀："串大流小压大"——变阻器阻值增大，总电流减小，定值电阻分压减小，变阻器分压增大。
🔥例18：比热容计算
质量为2kg的水，温度从20℃升高到70℃，吸收了多少热量？（c水=4.2×10³J/(kg·℃)）

解：

Δt=70-20=50℃

Q吸=cmΔt=4.2×10³×2×50=4.2×10⁵J

答：水吸收了4.2×10⁵J热量。

比热容计算三步：①确定Δt（末温-初温）②统一单位（质量kg、温度℃）③代入Q=cmΔt。注意"升高到"与"升高了"的区别。
🔥例19：热值计算与热效率
完全燃烧0.5kg的酒精（q=3.0×10⁷J/kg），放出的热量被20kg的水吸收，水温度升高了10℃，求：(1)酒精完全燃烧放出的热量；(2)水的吸热效率。

解：

(1)Q放=mq=0.5×3.0×10⁷=1.5×10⁷J

(2)Q吸=cmΔt=4.2×10³×20×10=8.4×10⁵J

η=Q吸/Q放×100%=8.4×10⁵/1.5×10⁷≈5.6%

热效率计算：η=有效利用热量/总放热量×100%。热机效率、加热效率都是这个思路，注意单位统一。
🔥例20：热机与能量转化综合
某汽油机飞轮转速为2400r/min，求：(1)每秒完成多少个工作循环？(2)每秒做功多少次？(3)每秒钟曲轴转几圈？

解：

(1)飞轮每秒转2400/60=40圈；一个工作循环曲轴转2圈，所以每秒20个循环

(2)每个循环做功1次，每秒做功20次

(3)每秒曲轴转40圈

热机规律：四冲程一个循环，曲轴转2圈，做功1次。飞轮转速除以2=每秒做功次数（循环数）。
