✅选择题通用策略

一、解题六步法：

  1. 审题：通读题目，圈出关键词和条件（已知/求/约束）
  2. 联想：快速联想相关知识点和解题方法
  3. 选择方法：根据题目特征选择最合适的解法
  4. 执行：快速计算或推理，得出结论
  5. 验证：将结果代入验证或用排除法确认
  6. 标记：不确定的题做标记，留待检查
时间分配：初中数学选择题建议每题1-2分钟，总时间控制在20-25分钟内。超时2分钟仍无思路的题先跳过。
🎯选择题核心技巧

1. 排除法（最常用）

  • 逐一验证选项，排除明显错误的选项
  • 适用于：概念判断题、不等式方向判断题、函数图象题
  • 关键：注意排除时要找"确定性"错误，不要猜

2. 特殊值法

  • 取满足条件的特殊值代入验证，快速排除或确定答案
  • 适用于：字母系数题、函数性质判断题、不等式恒成立题
  • 技巧：取0、1、-1、0.5等便于计算的特殊值

3. 代入验证法

  • 将选项逐一代入题目条件验证
  • 适用于：方程的解、不等式的解集、函数解析式
  • 技巧：优先代入中间选项，减少验证次数

4. 数形结合法

  • 画出函数图象或几何图形，直观判断
  • 适用于：函数图象题、几何性质判断题、坐标问题
  • 技巧：画图要准确，注意关键点和趋势

5. 估算法

  • 不精确计算，通过估算快速排除不合理选项
  • 适用于：计算量大的数值题、无理数比较大小
  • 技巧：注意估算范围，避免过度近似

6. 逆向思维法

  • 从结论出发，逆向推导验证
  • 适用于：几何证明选择题、条件充分性判断
  • 技巧：假设结论成立，看条件是否满足
⚠️选择题常见陷阱
陷阱类型表现应对策略
单位陷阱题目给cm，选项给m或mm审题时圈出单位，计算后检查单位一致性
符号陷阱正负号混淆、绝对值遗漏计算时每步标注符号，开方注意±
范围陷阱定义域限制、隐含条件注意分母≠0、根号内≥0、对数底数范围
多解陷阱只写一个解遗漏另一个绝对值方程、平方方程注意多解
图形陷阱特殊图形代替一般情况不能仅凭图形判断，需严格推理
概念陷阱相似概念混淆区分"轴对称"与"中心对称"等易混概念
口诀："一看二想三验证，排除代入加画图，特殊值法效率高，估算检查不马虎。"

📝 选择题示例

已知二次函数 y=ax²+bx+c 的图象如图所示，则下列结论正确的是（ ）
A. a>0   B. b>0   C. c<0   D. a+b+c>0
解题思路：①看开口方向判断a的符号（开口向下→a<0，排除A）；②看对称轴位置判断b的符号（对称轴在y轴右侧，且a<0，则b>0，选B）；③看与y轴交点判断c的符号（交于负半轴→c<0，C也正确）；④取x=1判断a+b+c的符号（对应点在x轴下方→a+b+c<0，排除D）。
✨ 技巧：二次函数选择题，"看开口→看对称轴→看y轴交点→看x轴交点→看特殊点"五步法快速判断。
✏️填空题核心策略

填空题特点：不需要写出过程，只写答案，但要求完全正确——一步算错，整题零分。

一、三大解题方法：

  • 直接计算法：按题目条件直接推导计算，最基本的方法
  • 数形结合法：画图辅助分析，适用于几何题和函数题
  • 特殊化方法：取特殊值或特殊图形，快速求解

二、填空题规范要求：

  1. 数值结果最简化（分数约分、根式化简）
  2. 注意单位（面积单位、角度单位）
  3. 多解题写所有答案，用逗号分隔
  4. 区间/范围用不等式或区间表示，注意端点
  5. 几何题写准确数值，不要写近似值
🧮填空题高频题型技巧
题型技巧要点易错提示
实数计算注意运算顺序、绝对值、幂的运算法则负数的奇偶次幂符号
因式分解先提公因式，再用公式法分解要彻底，不能半途而废
分式化简求值先化简再代入，注意分母不为零取值不能使分母为零
方程求解注意判别式判断根的情况二次项系数不能为零
不等式（组）注意不等号方向变化（乘负数时）解集端点是否取等号
几何计算画图标注已知条件，找等量关系注意分类讨论（钝角/锐角）
函数图象确定解析式，注意定义域实际问题的定义域限制
统计概率注意"有放回"与"无放回"区别概率结果化简为最简分数

📝 填空题示例

若关于x的一元二次方程 x²-4x+m=0 有两个不相等的实数根，则m的取值范围是 ______。
解题思路：方程有两个不相等的实数根 ⇒ 判别式 Δ > 0
Δ = b²-4ac = (-4)²-4×1×m = 16-4m > 0
解得：m < 4
✨ 易错点：不要遗漏"一元二次方程"意味着二次项系数≠0的前提。本题二次项系数恒为1，无需额外讨论。
📝解答题答题规范

一、答题四步法：

  1. 写"解"：每道题开头写"解："，表明开始答题
  2. 列条件：写出已知条件和所求（几何题先写"∵"或"已知："）
  3. 写过程：逻辑清晰，步骤完整，每步有依据
  4. 下结论：最后写"故..."或"∴..."给出明确结论

二、分步得分原则：

  • 即使不会完整解题，也要写出能写的步骤——公式、已知条件的转换
  • 每一步正确的推导都可能得分，不要留空
  • 关键步骤不能跳，尤其是几何证明的依据必须写明
阅卷提示：初中数学解答题通常按步骤给分，一般6-10分的题有4-6个得分点。即使最终答案错误，中间步骤正确也能获得部分分数。
📐几何证明题技巧

1. 分析法（执果索因）：

  • 从结论出发，逆向思考：要证A，需要B；要证B，需要C...
  • 找到已知条件与结论之间的逻辑链
  • 适用于：全等三角形、相似三角形、平行线证明

2. 综合法（由因导果）：

  • 从已知条件出发，正向推导出结论
  • 适用于：条件充分、思路清晰的题目

3. 常用辅助线：

题目特征辅助线目的
等腰三角形作底边上的高/中线/角平分线利用"三线合一"
直角三角形+斜边中点连接顶点与斜边中点利用斜边中线等于斜边一半
圆中弦作弦心距利用垂径定理
圆中直径构造直径所对圆周角利用直径所对圆周角为90°
梯形作高/平移腰/平移对角线转化为直角三角形或平行四边形
角平分线向两边作垂线利用角平分线性质

4. 证明书写规范：

  • 每步推理后写依据，如"(∵ SAS)" "(∵ 等边对等角)"
  • 推理链完整：A→B→C→...，不能跳跃
  • 结论要明确："∴ ∠ABC = ∠DEF" 或 "∴ △ABC ≌ △DEF"
📄代数解答题技巧

1. 方程/不等式应用题：

  • 设未知数：直接设或间接设，注意单位
  • 列方程：找等量关系，注意隐含条件
  • 解方程：注意检验根是否有实际意义
  • 作答：回答要完整，带单位

2. 函数综合题：

  • 求解析式：用待定系数法，设出一般式，代入已知点
  • 求交点：联立方程组求解
  • 求最值：利用顶点公式或配方法
  • 图象分析：注意开口方向、对称轴、顶点坐标

3. 统计概率题：

  • 画树状图或列表法求概率
  • 注意"有放回"和"无放回"的区别
  • 概率公式：P(A) = 有利结果数/总结果数
🏆压轴题突破策略

压轴题特点：分值高（通常10-14分）、综合性强、难度大，但并非不可攻克。

一、压轴题三问结构：

问号难度分值策略
第(1)问⭐3-4分基础题，必须拿下，通常是简单计算或证明
第(2)问⭐⭐4-5分中等题，需要综合运用，争取拿到大部分分数
第(3)问⭐⭐⭐3-5分难题，能写多少写多少，不空题
得分策略："第(1)问必拿分，第(2)问争高分，第(3)问不放弃"。即使第(3)问完全不会，也要写相关公式和已知条件的推导，争取步骤分。
🧮压轴题常见类型与解法

类型一：二次函数与几何综合

  • 核心思路：设点坐标→用函数解析式表示→建立方程/不等式→求解
  • 关键技巧：坐标系中距离公式、面积公式（割补法/铅垂法）
  • 常见考点：动点问题、存在性问题（等腰三角形/直角三角形/平行四边形）

类型二：几何变换综合

  • 核心思路：平移/旋转/翻折→找不变量→建立等量关系
  • 关键技巧：旋转构造全等三角形、翻折利用轴对称性质
  • 常见考点：旋转角度计算、翻折后图形性质、综合证明

类型三：动点问题

  • 核心思路：设时间t或参数→表示各点位置→列方程求解
  • 关键技巧：分类讨论（不同位置关系）、画不同阶段的示意图
  • 常见考点：动点形成的三角形/四边形面积、特殊图形存在性

类型四：阅读理解与新定义

  • 核心思路：理解新定义→模仿例题→应用解题
  • 关键技巧：仔细阅读定义，抓关键词，用具体数值验证理解
  • 常见考点：新运算定义、新图形定义、规律探究
💡压轴题提分建议
  1. 平时训练：每周精做2-3道压轴题，注重思路而非数量
  2. 分类突破：按题型分类练习，总结每类的通用解法
  3. 限时训练：模拟考试限时完成，训练时间分配能力
  4. 错题复盘：压轴题错题必须写出完整正确解答，总结错误原因
  5. 技巧积累：建立"技巧本"，记录常用辅助线、特殊结论、速算方法
  6. 心态调整：压轴题不是"绝杀题"，第(1)问和部分(2)问是可以拿分的

🕐时间管理实战技巧

1. "三轮做题法"：

  • 第一轮（60-70分钟）：做所有有把握的题，快速准确
  • 第二轮（20-30分钟）：攻克第一轮跳过的中等难度题
  • 第三轮（10-15分钟）：冲击压轴题+检查

2. "时间红线"机制：

  • 选择题每题红线：3分钟（超时跳过）
  • 填空题每题红线：4分钟（超时跳过）
  • 解答题每题红线：8分钟（超时先写能写的步骤）
  • 压轴题第(3)问红线：10分钟（写公式和思路就停）

3. 跳题标记法：

  • 跳过的题在试卷上做明显标记（画圈/折角）
  • 在答题卡对应位置先写"解："，避免漏答
  • 做完后面的题回来时，心态更放松，可能突然有思路
🔍检查策略

一、检查优先级（从高到低）：

  1. 高分题优先：压轴题、大分值解答题
  2. 易错题优先：计算量大、分类讨论的题
  3. 跳过的题：第一轮没做出的题，回来重新思考
  4. 选择题填空题：快速过一遍，确认填涂位置
  5. 答题卡：检查是否漏涂、错位

二、检查方法：

题型检查方法注意事项
选择题用不同方法重新验证（如排除法→代入法）无充分理由不轻易改答案
填空题重新计算+单位检查+多解检查分数约分、根式化简
计算题逆运算验证（如除法用乘法验）每步符号、小数点
方程题把解代入原方程验证注意增根、实际意义
几何证明重新审视推理链是否完整依据是否写全
应用题答案是否符合实际意义单位、取舍

三、检查清单：

  • 答题卡填涂位置是否正确
  • 每道题是否都写了答案（无空题）
  • 选择题是否全部填涂（不漏涂）
  • 填空题答案是否最简形式
  • 计算题每步是否有"="\连接
  • 几何证明每步是否写明依据
  • 应用题是否写了"答："
  • 压轴题是否写了能写的步骤
  • 姓名、考号是否填写

🔹初一数学学习重点

初一数学是小学到初中的过渡阶段，核心是从算术思维向代数思维转变。

核心知识模块：

  • 有理数：正负数运算、绝对值、数轴
  • 整式加减：字母表示数、合并同类项
  • 一元一次方程：等式性质、解方程步骤
  • 几何图形初步：线段、角、平行线
  • 数据的收集与整理：统计图表
初一最大挑战：从"数字计算"到"字母运算"的思维转变。很多学生不适应用字母表示数，导致后续代数学习困难。
💡初一考试技巧
  1. 符号意识：有理数计算中正负号是最大失分点，建议每步标注符号
  2. 方程思维：学会用方程解决问题，设未知数→列方程→解方程→检验作答
  3. 画图习惯：几何题必须画图，在图上标注已知条件
  4. 计算规范：去括号注意符号变化，移项注意变号
  5. 应用题：行程问题、工程问题、利润问题要找等量关系

📝 初一典型易错

计算：(-2)³ ÷ (-2)²
正确解法：(-2)³ = -8，(-2)² = 4
∴ (-2)³ ÷ (-2)² = -8 ÷ 4 = -2
常见错误：将(-2)³算成8（忽略负号），得到8÷4=2
✨ 记忆口诀：负数的奇数次幂为负，偶数次幂为正。

📝 初三典型易错

已知抛物线 y=ax²+bx+c 经过点A(-1,0)、B(3,0)、C(0,3)，求抛物线解析式。
解法（交点式）：
∵ 抛物线与x轴交于A(-1,0)、B(3,0)
∴ 设 y=a(x+1)(x-3)
代入C(0,3)：3=a(0+1)(0-3)=a×(-3)
∴ a=-1
∴ y=-(x+1)(x-3)=-x²+2x+3
验证：代入A(-1,0)：-1-2+3=0 ✓；代入B(3,0)：-9+6+3=0 ✓
✨ 技巧：已知与x轴交点时，用交点式 y=a(x-x₁)(x-x₂) 最快捷。

🔢代数高频易错点
1. 负数幂的符号判断错误▼

错误表现：将(-2)³算成8，或将-2²算成4

正确理解：-2² = -(2²) = -4，而(-2)² = 4。括号改变一切！

口诀："负数幂看指数，奇负偶正看清楚；不加括号是相反数。"

2. 绝对值化简遗漏分类讨论▼

错误表现：|a-b| = a-b（没有讨论a与b的大小关系）

正确做法：|a-b| = a-b（当a≥b时）或 b-a（当a<b时）

提示：遇到绝对值，先判断内部表达式正负，再去绝对值符号。

3. 解方程时忘记检验增根▼

错误表现：分式方程解出后不代入检验，保留增根

正确做法：分式方程必须将解代入最简公分母检验，使分母为0的解是增根，必须舍去。

例：解 1/(x-1) + 2 = 1/(x-1)，得x=1，但x=1使分母为0，是增根，原方程无解。

4. 不等式方向变化遗漏▼

错误表现：不等式两边乘以/除以负数时，忘记变号

正确做法：不等式两边乘以或除以同一个负数时，不等号方向必须改变。

例：-2x > 6 → x < -3（注意方向变化）

5. 因式分解不彻底▼

错误表现：x⁴-16 = (x²+4)(x²-4)，到此为止

正确做法：x⁴-16 = (x²+4)(x²-4) = (x²+4)(x+2)(x-2)

原则：因式分解必须分解到不能再分解为止（实数范围内）。

6. 科学记数法中n的确定▼

错误表现：将 0.0000314 写成 3.14×10⁴

正确做法：0.0000314 = 3.14×10⁻⁵（小数点右移5位，n=-5）

规则：原数≥1时n为正整数；原数<1时n为负整数。n的绝对值等于小数点移动的位数。

7. 幂的运算性质混淆▼

常见混淆：

· a²·a³ = a⁵ (不是a⁶) — 同底数幂相乘，指数相加

· (a²)³ = a⁶ (不是a⁵) — 幂的乘方，指数相乘

· a⁶÷a² = a⁴ (不是a³) — 同底数幂相除，指数相减

口诀："乘除加减，乘方乘乘，记住别混。"

📐几何高频易错点
1. 全等三角形判定条件不足▼

错误表现：用SSA（边边角）判定全等，或三个角对应相等(AAA)判定全等

正确判定：SAS、ASA、AAS、SSS、HL（直角三角形专用）

注意：SSA和AAA不能判定两个三角形全等！

2. 勾股定理使用前提遗漏▼

错误表现：在非直角三角形中使用勾股定理

正确做法：勾股定理只适用于直角三角形。使用前必须确认（或构造）直角三角形。

技巧：遇到一般三角形，可以通过作高构造直角三角形。

3. 相似三角形对应边比例写反▼

错误表现：△ABC∼△DEF时，写成AB/DE=EF/BC

正确做法：对应顶点字母对应，对应边成比例：AB/DE = BC/EF = AC/DF

技巧：先找对应顶点，再按顺序写对应边。

4. 圆的切线判定条件不完整▼

错误表现：只证"经过半径外端"或只证"垂直于半径"

正确做法：切线判定需要同时满足两个条件：①经过半径的外端；②垂直于这条半径。

口诀："切线判定两条件，过端点、垂直半径缺一不可。"

5. 圆周角定理应用中忽略同弧▼

错误表现：不同弧所对的圆周角也认为相等

正确理解：同弧或等弧所对的圆周角相等，且等于所对圆心角的一半。

注意："同弧"是指同一条弧，不同弧即使度数相同也不一定相等。

6. 几何计算中分类讨论遗漏▼

错误表现：三角形高在哪边没讨论、点在弧上位置没讨论

常见需要分类讨论的情况：

· 等腰三角形：已知两边长，需讨论哪两条是腰

· 直角三角形：已知两边，需讨论哪条是斜边

· 圆中：点在优弧还是劣弧上

· 相似三角形：对应关系不确定时

7. 平行四边形判定条件不全▼

错误表现：只用"一组对边平行"就判定平行四边形

正确判定：以下任一条件即可：①两组对边分别平行；②两组对边分别相等；③一组对边平行且相等；④对角线互相平分；⑤两组对角分别相等。

注意："一组对边平行"不一定是平行四边形（可能是梯形）。

📉函数高频易错点
1. 一次函数k、b的几何意义混淆▼

错误表现：不清楚k和b分别决定什么

正确理解：y=kx+b中，k决定倾斜方向（k>0增函数，k<0减函数），b决定与y轴交点（b>0交于正半轴，b<0交于负半轴）。

注意：|k|越大，直线越陡。

2. 二次函数顶点坐标公式记错▼

错误表现：顶点横坐标写成b/2a（忘记负号）

正确公式：y=ax²+bx+c的顶点坐标为 (-b/2a, (4ac-b²)/4a)

记忆口诀："负b比2a是横坐标，4ac减b方比4a是纵坐标。"

3. 抛物线开口方向与a的关系▼

错误表现：a>0时画成开口向下

正确理解：a>0 → 开口向上（有最小值）；a<0 → 开口向下（有最大值）。

联想：y=x²开口向上（a=1>0），记忆基准。

4. 反比例函数图象象限判断错误▼

错误表现：k>0时画在一、三象限但方向画反

正确理解：y=k/x：k>0 → 一、三象限（每个象限内y随x增大而减小）；k<0 → 二、四象限（每个象限内y随x增大而增大）。

注意：反比例函数图象无限接近坐标轴但永不相交。

5. 函数图象交点与方程组的关系▼

错误表现：不理解交点坐标的含义

正确理解：两个函数图象的交点坐标 = 联立方程组的解。

应用：求交点就是解方程组；方程无解则图象无交点。

6. 二次函数与一元二次方程的关系混淆▼

正确理解：

· 二次函数y=ax²+bx+c与x轴交点 ⇔ 方程ax²+bx+c=0的实数根

· Δ>0：两个交点；Δ=0：一个交点（相切）；Δ<0：无交点

· 交点横坐标就是方程的根

📊统计概率高频易错点
1. 中位数计算忘记排序▼

错误表现：直接取中间位置的数，不先排序

正确做法：先将数据从小到大排列，再取中间的数。偶数个数据取中间两个的平均值。

2. "有放回"与"无放回"混淆▼

错误表现：无放回抽取时按有放回计算概率

区分："有放回"每次抽取总数不变；"无放回"每次抽取总数递减。

例：袋中3红2白球，摸两次。
有放回：第二次仍3红2白共5个
无放回：第一次摸完后只剩4个

3. 方差与标准差概念混淆▼

正确理解：方差S²是各数据与平均数差的平方的平均值；标准差S是方差的算术平方根。

注意：方差越大，数据波动越大；方差越小，数据越稳定。

4. 概率结果未化简▼

错误表现：概率写成4/8而不是1/2

正确做法：概率结果必须化为最简分数。

5. 树状图/列表法遗漏情况▼

错误表现：画树状图或列表时遗漏某些情况

正确做法：树状图每层分支要完整，列表法确保所有组合都列出。完成后检查总数是否符合预期。

验证：两步实验总数=第一步可能数×第二步可能数。

6. 加权平均数计算错误▼

正确公式：加权平均数 = (Σ权重×数值) / (Σ权重)

注意：权重之和不一定为1，需要除以权重总和。

🔢例1：一元二次方程综合
已知关于x的方程 x²-(k+1)x+k²+1=0 有两个实数根x₁、x₂。
(1) 求k的取值范围；
(2) 若x₁²+x₂²=5，求k的值。

第(1)问：

Δ = (k+1)²-4(k²+1) = k²+2k+1-4k²-4 = -3k²+2k-3

Δ ≥ 0 ⇒ -3k²+2k-3 ≥ 0 ⇒ 3k²-2k+3 ≤ 0

Δ' = (-2)²-4×3×3 = 4-36 = -32 < 0，且3>0

∴ 3k²-2k+3 > 0 恒成立，即 Δ < 0 恒成立

等等！这里Δ<0意味着方程无实数根！

让我们重新检查：Δ = -3k²+2k-3，判别式 = 4-36 = -32 < 0，且二次项系数-3<0

∴ Δ < 0 恒成立，方程没有实数根。

结论：原方程不可能有两个实数根，题目条件矛盾。

✨ 此题的关键在于计算判别式并正确判断。

解题技巧：遇到"已知方程有实数根"的条件，第一步永远是计算判别式Δ≥0，建立不等式求参数范围。
🔢例2：分式化简求值
先化简，再求值：(x²-1)/(x²+2x+1) ÷ (x-1/x) ，其中x从-1、1、2中选择一个合适的值代入。

第一步：化简

原式 = (x+1)(x-1)/(x+1)² ÷ (x²-1)/x

= (x-1)/(x+1) ÷ (x-1)(x+1)/x

= (x-1)/(x+1) × x/[(x-1)(x+1)]

= x/(x+1)²

第二步：选值

x=-1：使分母x+1=0，不可取

x=1：使原式中x-1=0（除式为0），不可取

x=2：满足条件，代入得 2/(2+1)² = 2/9

答案：2/9

解题技巧：分式化简求值题，选择x值时必须使原式和化简后的式子都有意义（分母≠0，除式≠0）。
📐例3：全等三角形证明
如图，在△ABC中，D是BC的中点，DE⊥AB于E，DF⊥AC于F，且DE=DF。求证：△ABC是等腰三角形。

证明：

∵ DE⊥AB，DF⊥AC

∴ ∠DEB = ∠DFC = 90°

在Rt△BDE和Rt△CDF中：

∵ DE = DF（已知）

BD = CD（D是BC中点）

∴ Rt△BDE ≌ Rt△CDF (HL)

∴ ∠B = ∠C（全等三角形对应角相等）

∴ AC = AB（等角对等边）

∴ △ABC是等腰三角形

证明技巧：等腰三角形的证明常用"全等→等角→等边"的思路链。注意HL定理仅适用于直角三角形。
📐例4：圆的综合计算
如图，AB是⊙O的直径，弦CD⊥AB于E，CD=8，BE=2，求⊙O的半径。

解：

设⊙O的半径为r，则OA=OB=r

∵ AB是直径，CD⊥AB

∴ CE=ED=CD/2=4（垂径定理）

∵ BE=2 ∴ OE=OB-BE=r-2

在Rt△OCE中：OE²+CE²=OC²

(r-2)²+4²=r²

r²-4r+4+16=r²

-4r+20=0

r=5

答：⊙O的半径为5。

解题技巧：圆中弦的计算必用垂径定理（弦心距+半弦长+半径构成直角三角形），用勾股定理建立方程。
📉例5：二次函数综合
已知抛物线 y=-x²+2x+3 与x轴交于A、B两点（A在B左侧），与y轴交于点C。
(1) 求A、B、C三点坐标；
(2) 求△ABC的面积；
(3) 在抛物线上是否存在点P，使S△PAB=S△ABC？若存在，求出P点坐标。

第(1)问：令y=0：-x²+2x+3=0 ⇒ x²-2x-3=0 ⇒ (x-3)(x+1)=0 ⇒ x=-1或x=3

∴ A(-1,0)，B(3,0)

令x=0：y=3 ∴ C(0,3)

第(2)问：AB=3-(-1)=4，C到AB的距离=3

S△ABC = ½×4×3 = 6

第(3)问：设P(x,y)，S△PAB=½×AB×|y|=½×4×|y|=2|y|

2|y|=6 ⇒ |y|=3 ⇒ y=3或y=-3

y=3：-x²+2x+3=3 ⇒ -x²+2x=0 ⇒ x=0或x=2 ⇒ P₁(0,3)即C点，P₂(2,3)

y=-3：-x²+2x+3=-3 ⇒ x²-2x-6=0 ⇒ x=1±√7 ⇒ P₃(1+√7,-3)，P₄(1-√7,-3)

答：存在，P(2,3)或P(1+√7,-3)或P(1-√7,-3)。（C点除外）

解题技巧：二次函数面积问题常用"底×高÷2"，以x轴上两点为底时，高就是纵坐标的绝对值。注意分类讨论和去重。
📉例6：一次函数与几何综合
直线y=-2x+4与x轴交于A，与y轴交于B。求：(1)A、B坐标；(2)△AOB的面积；(3)在直线AB上是否存在点P，使△AOP为等腰三角形？

第(1)问：令y=0：x=2，∴A(2,0)；令x=0：y=4，∴B(0,4)

第(2)问：S△AOB=½×2×4=4

第(3)问：等腰三角形需分类讨论哪两边相等，此题需结合图形分析，注意P点在直线上的限制条件。

解题技巧：等腰三角形存在性问题必须分类讨论（AB=AP、AB=BP、AP=BP三种情况），注意排除重合和共线的情况。
💼例7：利润最值问题
某商店以每件30元进价购进商品，按每件40元出售，每天可售出300件。经市场调查发现，单价每提高1元，销售量减少10件。问定价为多少时，每天利润最大？最大利润是多少？

解：设定价提高了x元，则：

售价 = 40+x 元/件

销量 = 300-10x 件/天

利润 W = (40+x-30)(300-10x) = (10+x)(300-10x)

= 3000-100x+300x-10x² = -10x²+200x+3000

当 x = -b/2a = -200/(-20) = 10 时，W取最大值

定价 = 40+10 = 50 元/件

最大利润 W = -10×100+200×10+3000 = 4000 元

答：定价50元/件时，每天最大利润4000元。

解题技巧：利润最值问题建模为二次函数，用顶点公式求最值。注意变量的实际意义（售价>0，销量>0）。
🚗例8：行程问题
甲乙两人同时从A地出发去B地，甲速度为5km/h，乙速度为3km/h。甲到达B地后立即返回，在途中与乙相遇。若A、B相距16km，求两人相遇时乙走了多远。

解：设两人相遇时乙走了x km，则：

乙走的距离 = x km，用时 = x/3 小时

甲走的距离 = 16+(16-x) = 32-x km，用时 = (32-x)/5 小时

两人用时相等：x/3 = (32-x)/5

5x = 3(32-x) ⇒ 5x = 96-3x ⇒ 8x = 96 ⇒ x = 12

答：相遇时乙走了12km。

解题技巧：行程问题的核心是找等量关系，通常是"时间相等"或"路程关系"。画线段图辅助分析。
